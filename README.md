# Курсовая работа: Резервное копирование картинок с cataas.com

Программа загружает картинки с котами и пользовательским текстом напрямую на Яндекс.Диск.

## 📁 Название папки на Яндекс.Диске
`PY-140`

## 🚀 Как запустить

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
2. Создайте файл .env в корне проекта:
   YANDEX_DISK_TOKEN=ваш_токен_с_Полигона_Яндекса
3. Запустите программу:
   python main.py
4. Введите текст — картинка сохранится на Яндекс.Диск и в backup_info.json.
📄 Файлы
main.py — основная программа
requirements.txt — зависимости
.gitignore — исключённые файлы (токен, логи и т.д.)
